# Playzoni languages — spec v2, 11 Nov 2026 (v1 + changes from docs/SEO-INTL.md)

Owner wants the site in several languages, chosen from the visitor's country. Google's guidance: **do not auto-redirect people by IP or browser language** (Googlebot crawls mostly from the USA without a language header, so it would never see the other versions). So we detect the country, but we **suggest**, we do not force.

## URLs (v2)
- Language folder + **translated category slugs**, same game slugs: `/es/juegos-de-carros`, `/es/game/<slug>`, `/de/autospiele`. The map of category slugs per language lives in `data/i18n/category-slugs.json` (`{ "car-games": { "es": "juegos-de-carros", … } }`); the build fails if a published category has no slug in a live language. Slugs: lowercase ASCII, `-` (Russian slugs transliterated, e.g. `igry-gonki`).
- Fixed page slugs per language in the same file (`new-games`, `popular-games`, `all-games`, `categories`, `about`…).
- **hreflang in per-language XML sitemaps** (`/sitemap-<lang>.xml` with `xhtml:link` alternates, self-reference, return tags, `x-default` = English) plus `<link rel="alternate">` in HTML on home and category pages. Only link versions that exist and are published.
- Canonical = the page itself in its own language. `<html lang="<code>">` per page.

## Choosing the language
1. A Cloudflare Pages Function on `/__geo` returns the visitor's country from Cloudflare's `CF-IPCountry` header (free, no IP stored).
2. On English pages, visitors from a mapped country see a small dismissible bar at the top: "Jogar em português? → Mudar" (one line, in that language). Clicking switches to the same page in that language and saves the choice in a `pz_lang` cookie (1 year). "No thanks" hides it for 30 days.
3. Only after a visitor **chose** a language do we send them there automatically on the **home page** (`/` → `/pt`). Never for Googlebot or other bots, never on deep links.
4. A language picker in the footer (like Poki) on every page.

## Translation (quality rules in SEO-INTL §6)
- UI strings: `src/i18n/<lang>.json`, one key per string, English as the source. Missing keys fail the build.
- Game and category texts: translated by Claude from the English text (which comes from real play-testing), with a native speaker spot-checking 10% of pages per language before launch. Never machine-translate the feed text.
- Only translate pages that are published in English. A language goes live when its UI strings are complete and ≥ 100 game pages are translated and checked.
- Russian uses Cyrillic (Nunito covers it); Hindi uses Devanagari → system font fallback, check line heights.
- Search panel: `fuzzy-search.ts` gets per-language `CATEGORY_WORDS` (e.g. `carro`, `coche`, `auto`, `voiture`, `машина`) and accent-insensitive matching (already in `clean()`); Cyrillic needs its own `soundsLike` rules (T8.6).
